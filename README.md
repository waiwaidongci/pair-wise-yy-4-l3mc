# 水下考古潜水记录 · 脱盐监护台

直接打开 `index.html` 使用。页面分两个页签：

- **潜水图与标记**：点击沉船平面图添加标记，支持类型筛选、编辑、删除、潜次时间线和导出 JSON（原有功能）。
- **脱盐监护台**：出水遗物脱盐槽的换水监护与结批存档。

## 脱盐监护台

- 每件遗物登记：槽号、材质、入槽时刻、最近电导率、换水记录（在“潜水图与标记”表单或监护台弹窗中维护）。
- **待换水判定**（满足任一即留在待换水，不可结批）：
  1. 最新电导率高于阈值（默认 100 μS/cm，可调）；
  2. 距最近换水（无换水记录则自入槽时刻）不足最短间隔（默认 24 小时，可调）；
  3. 同槽混放不同材质（整槽列入“异常”）。
- **复核结批**：当前批次全部槽位达标后，复核员逐槽填入排水量（L）与余盐（mg/L）方可结批；结批后快照存档并自动开启新批次。
- **读数更正**：补录、更正或删除历史读数（含已结批遗物）会使原批次作废留档（存档卡盖“作废”标记），该批遗物按新数据回到当前批次重新判定。
- 监护台按槽位分“待换水 / 异常 / 结批存档”三列展示；槽位与状态筛选、JSON 导出均跟随当前批次。

## 文件结构

- `js/desalination.js` — 脱盐判定（纯逻辑：阈值、间隔、材质冲突）
- `js/batch.js` — 批次存档（结批快照、作废重判、localStorage 持久化）
- `js/app.js` — 页面操作（地图、表单、时间线、看板、弹窗、筛选与导出）

数据保存在浏览器 localStorage（`zfl30Marks` / `zfl30Batches` / `zfl30DesalSettings`）。首次打开自带演示数据：达标槽、超标槽、间隔不足槽、材质冲突槽与一条已结批存档，便于直接体验完整流程。
